## Publish with GitHub Pages

1. Upload the contents of this folder to your GitHub Pages repository.
2. Keep `index.html` at the repository root.
3. Keep the `assets` folder beside it.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → `main` / root.
